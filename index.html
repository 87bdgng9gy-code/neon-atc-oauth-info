NEON ATC

NEON ATC is a private operator application. It uses Google OAuth to access Google Drive files and folders that the operator opens with the application, or that the application creates.

It requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. It does not request access to the operator’s entire Google Drive.

This site exists so that Google OAuth users can identify the application and review its Google user-data practices.
